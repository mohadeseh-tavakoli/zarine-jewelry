# ZARINÉ — نسخه مستقل HTML/CSS/JavaScript

## اجرا
فایل `index.html` را در مرورگر باز کنید یا پوشه را روی GitHub Pages منتشر کنید.

## صفحات
- `index.html` صفحه اصلی
- `shop.html` فروشگاه با فیلتر دسته‌بندی و مرتب‌سازی
- `product.html` جزئیات محصول
- `cart.html` سبد خرید آزمایشی
- `about.html` درباره زرینه
- `contact.html` تماس با ما

## تصاویر
تصاویر واقعی ارسالی در `assets/images/` قرار گرفته‌اند. تصویر مدل برای بنر اصلی و ۸ تصویر دیگر برای محصولات استفاده شده‌اند.

## نکته مهم
قیمت‌ها و وزن‌های نمایش‌داده‌شده در نسخه نمایشی، نمونه هستند و اطلاعات تأییدشده فروشگاهی محسوب نمی‌شوند. سبد خرید با `localStorage` کار می‌کند و پرداخت واقعی ندارد.
